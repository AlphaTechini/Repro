## Built but not verified end to end (needs keys or network)

- Reading a real Clip. `clips.agent-native.com` was unreachable from the build sandbox, so parsing is tested only on fixtures shaped like the Clips source (`tests/fixtures/clips/`, `shared/repro/lib/clips-parse.ts`).
- Clip iframe embed and frames (`app/components/repro/evidence/ClipPlayer.tsx:61-73`, `FrameGrid`).
- The GitHub App JWT and installation flow (`server/lib/repro/github-app.ts:65-75` and `:155-172`, `server/routes/github/setup.get.ts`).
- Issue creation, labels and comments (`actions/file-github-issue.ts:83-91`, `actions/mark-duplicate.ts:127-130`).
- GitHub issue similarity search (`actions/find-similar-reports.ts:52-58`).
- The runtime agent loop with a real model. The sandbox has no model key. The prompt is at `server/plugins/agent-chat.ts:31-35`.
- Agent flash highlight and the duplicate banner (`app/components/repro/report/ReportView.tsx:221-251`, `:172-193`, `:346`).

## Not built

- Pull request creation or code fixes (out of scope; the GitHub App has no code or pull-request permissions).
- Anonymous external reporters and the embedded recorder (roadmap).
- The mobile agent sidebar opens over the report on first load. This is the Agent-Native toolkit's behaviour and Repro does not change it.
- `evidence/metrics.json`: `pnpm action export-metrics` writes it (`actions/export-metrics.ts:17`), but no real-run metrics exist yet. Only `evidence/capability-checks.md` is present.
- The GitHub Setup URL is not tied to the signed-in user. Any signed-in user with a valid installation ID of this app can attach it (`server/routes/github/setup.get.ts:11-15`). The fix is GitHub's OAuth-during-install flow.

## Pre-existing vs built during the hackathon

- Pre-existing: Agent-Native `chat` template scaffolded by `npx @agent-native/core@latest create repro-test --standalone --template chat` (core 0.223.0) on Nov 3, 2026, then renamed to `repro` in package.json. All files in the first commit except `checks/`, `docs/`, `evidence/` and the edited `AGENTS.md`, `CLAUDE.md`, `.env.example`, `README.md`, `package.json` name/description.

For Repro this is `actions/`, `server/lib/repro/`, `shared/repro/`, `app/components/repro/`, `app/routes/reports*`, `app/routes/metrics.tsx`, `server/routes/github/setup.get.ts`, `tests/`, `scripts/verify-demo.ts` and `.agents/skills/repro/SKILL.md`.
